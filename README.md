<h2 align="center"><img src="https://cdn.simpleicons.org/github/58A6FF" width="22" /> &nbsp;Sobre Mí</h2>

Soy egresado de Ingeniería en Sistemas Computacionales, enfocado principalmente en el desarrollo Backend utilizando **PHP**.

Mi experiencia técnica radica en la construcción de sistemas web, el diseño y consumo de **APIs REST**, programación orientada a objetos (POO) y el manejo de bases de datos relacionales estructuradas.
